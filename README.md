# bellavistarestaurant

A responsive restaurant website built using **HTML and CSS** that showcases a modern layout for an Italian restaurant. The website includes sections such as a hero landing page, menu display, about section, and a reservation/contact form.

This project was created to practice **frontend web development fundamentals** including layout design, responsive styling, and UI structuring.

---

## 🚀 Features

- Responsive website layout
- Fixed navigation bar
- Hero section with background image
- Menu section with styled food items
- About section with restaurant story
- Contact information and reservation form
- Footer with quick links and social media
- CSS animations and hover effects
- Mobile-friendly design using media queries

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- Flexbox
- CSS Grid
- CSS Animations
- Media Queries (Responsive Design)

## 📸 Website Sections

The website contains the following sections:

- **Home (Hero Section)** – Welcome message and call-to-action buttons
- **Menu** – Displays restaurant dishes with descriptions and prices
- **About** – Information about the restaurant story
- **Contact** – Contact details and reservation form
- **Footer** – Quick links, opening hours, and social media links
